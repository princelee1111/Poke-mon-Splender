# 璀璨宝石：宝可梦 · 联机对战（Poké Splendor Online）

基于桌游《璀璨宝石：宝可梦》（Pokémon Splendor）的 2-4 人联机对战网站，完整实现官方规则书 v1.1 的全部核心规则，卡面素材与数值与实体桌游一致。

## 功能特性

- **完整规则实现**（依据官方英文规则书 v1.1）：
  - 6 种精灵球：精灵球(红)/超级球(蓝)/高级球(黑)/治愈球(粉)/先机球(黄)/大师球(紫·万能)
  - 四种回合行动：拿 3 个不同色球 / 拿 2 个同色球(供给≥4) / 保留 1 张卡+1 大师球(手牌上限 3) / 捕捉宝可梦
  - 稀有/传说卡必须消耗至少 1 个大师球，且提供双倍折扣
  - 进化系统：回合结束时结算，只看已捕捉宝可梦的折扣，不消耗、每回合至多 1 次，目标卡须在场上或保留区
  - 10 球上限、18 胜点终局（打完本轮）、平局判定（进化数→宝可梦数）
  - 2/3/4 人局的供给调整（-3/-2/0，大师球恒 5 个）
- **多人联机**：房间制（4 位房间号）、服务器权威校验、SSE 实时推送、断线自动重连（token 绑定座位）
- **Bot 补位**：启发式 AI，可随时添加，支持单人测试
- **卡牌数据**：100 张卡（一阶 35 / 二阶 30 / 三阶 15 / 稀有 10 / 传说 10），中文名、费用、折扣、进化链均与实体卡面一致，卡图为实际卡面扫描图（WebP）
- **宝可梦主题 UI**：精灵球代币、按实体桌面布局的牌堆列+卡牌行+供给区、捕捉/进化/弃球/胜利弹窗、战斗日志

## 运行

```bash
node server.js
# 打开 http://localhost:3000
```

零第三方依赖（纯 Node.js 内置模块），端口默认 3000（`PORT` 环境变量可覆盖）。

## 项目结构

```
server.js          HTTP 服务器：静态资源 + 房间 API + SSE 推送 + bot 调度
engine.js          纯逻辑游戏引擎（规则/进化/计分/脱敏，可单测）
bot.js             启发式 AI bot
data/cards.json    卡牌数据库（100 张）
public/            前端（index.html + style.css + app.js）
public/assets/     卡面图片（100 张 WebP）
test.js            自测脚本：44 条规则断言 + 200 局 bot 自走
```
